# Paradise Nursery Shopping Application

## Project Name
Paradise Nursery

## Project Description
Paradise Nursery is a React-based online plant shopping application. It allows users to browse different categories of houseplants, view plant details, add plants to a shopping cart, manage quantities, and calculate the total cost of selected plants.

## Technologies Used
- React.js
- Redux Toolkit
- JavaScript
- HTML
- CSS

## Features
- Paradise Nursery landing page
- Plant categories
- Plant product listing
- Add to Cart functionality
- Dynamic cart item count
- Increase/decrease item quantity
- Remove items from cart
- Dynamic price calculation
- Checkout functionality
